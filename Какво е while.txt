What is `while`?

The basic idea is:

"As long as this condition is True, execute this code."

Example:

number = 1

while number <= 5:
print(number)
number += 1

Result:

1
2
3
4
5

Here:

number <= 5 → the condition
print(number) → what to repeat
number += 1 → we change the value so that the condition can eventually become False

⚠️ Very important: if you never change the value so that the condition becomes False, you might end up with an infinite loop.

Exercise 5 — Password

Create a program that has a preset password:

password = "python123"

The user must enter the password.

If it is correct → Access granted!
If it is incorrect → ask for the password again.

Example:

Wrong password!

Enter password: 12345
Wrong password!

Enter password: python123
Access granted!

💡 The main idea is:

"As long as the password isn't correct, keep asking."
